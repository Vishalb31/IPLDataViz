🏏 IPL Power BI Dashboard

This Power BI project presents an in-depth analysis of IPL (Indian Premier League) data with multiple insightful visualizations across different aspects of the tournament.

📂 Project Overview
This dashboard allows users to explore key statistics and trends across various dimensions such as team performance, player contributions, venue influence, and match outcomes.
________________________________________

📊 Dashboard Pages & Insights
🏠 1. Home Page
•	Overview of the entire dashboard with navigation buttons to explore Batting, Bowling, Match Analysis, and Venue Analysis.
•	Offers a clean and interactive starting point for the user.
🏏 2. Batting Analysis
•	Top run-scorers and consistent performers across seasons.
•	Strike rate comparison among top players.
•	Team-wise batting performance.
•	Year-wise batting evolution.
•	Insights into boundaries, averages, and contributions to team totals.
🎯 3. Bowling Analysis
•	Top wicket-takers across seasons.
•	Economy and strike rate comparison for bowlers.
•	Performance in powerplay, middle overs, and death overs.
•	Team-wise bowling strength visualization.
•	Dot ball percentages and match impact metrics.
📈 4. Match Analysis
•	Match outcomes by team and toss decisions.
•	Win margin analysis (by runs/wickets).
•	Season-wise match summaries.
•	Insights on winning trends and chasing vs defending success rates.
🏟️ 5. Venue Analysis
•	Performance trends across different stadiums.
•	Most successful teams per venue.
•	Toss and match win correlation by venue.
